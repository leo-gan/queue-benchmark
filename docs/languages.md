# Supported Languages and Queues

- **C#**: ConcurrentQueue, Channel, BufferBlock, BlockingCollection, etc.
- **Python**: asyncio.Queue, queue.Queue, janus, redis-py, celery, etc.
- **JavaScript**: fastq, p-queue, bullmq, Array.shift, etc.
- **Rust**: std::sync::mpsc, crossbeam-channel, flume, tokio, etc.
- **C**: POSIX mq, ZeroMQ, liblfds, etc.
